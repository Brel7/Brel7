## What I work on

I build web, mobile and backend software, and I study cybersecurity engineering. The two meet in GovTech: public-service platforms for Gabon and Africa that have to be usable and hard to break.

My SOC lab runs TheHive, Cortex, YARA and CAPE. I use it to detonate samples in an isolated VM, write detection rules and track each case from alert to closure.

I'm looking for a PFE internship in cybersecurity.
